
## Experiment 3: Iterative Prompt Refinement

### Aim
To improve an explanation of photosynthesis for a 10-year-old
through iterative prompt refinement.

### Tools Required
- Python
- Google Colab
- Gemini API
- google-genai library

### Iterations
- Iteration 0: Baseline prompt.
- Iteration 1: Add an analogy, simple language and a length limit.
- Iteration 2: Add a memory trick and a text-only diagram description.

### Result
Three prompt versions were sent to the Gemini API.
Their responses were displayed and saved for comparison.
The refinements aimed to improve simplicity, clarity and memorability.
